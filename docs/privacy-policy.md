## English

**Conduit Uploader** is the Google OAuth client used by the [Conduit](https://github.com/rhlfur2055-prog/conduit) workflow automation tool to upload videos to, and manage statistics and comments on, the operator's own YouTube channel.

- **Who uses it**: a single operator (the developer) on their own account and channel. It is not distributed to the public.
- **Data accessed**: only the YouTube scopes the account owner consents to (`youtube`, `youtube.upload`, `youtube.force-ssl`) — channel info, video upload, video statistics and comment posting.
- **Where data is stored**: OAuth tokens are stored only in a local configuration file (`.env`) on the operator's computer. Nothing is sent to any external server or shared with third parties.
- **Not collected or sold**: no personal data of other people is collected; no tracking for advertising or analytics; no data is sold.
- **Deletion**: the operator can revoke access at any time on the [Google account permissions page](https://myaccount.google.com/permissions), and deleting the token from the local `.env` removes all stored data.
- **Google API Services User Data Policy**: this app's use of Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.
